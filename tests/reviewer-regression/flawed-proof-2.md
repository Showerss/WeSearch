# Flawed proof 2

**Claim:** Every connected graph with n vertices has a spanning tree with exactly n - 1 edges, therefore every graph with n vertices and n - 1 edges is a tree.

**Proof:** The first part is standard. For the second, clearly a graph with n - 1 edges must be connected, so it is a tree.

(The second part is false: a triangle plus an isolated vertex has 4 vertices and 3 edges but is disconnected. "Clearly" hides the gap.)
